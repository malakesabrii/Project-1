# KidsMeals Brand Assets

این پوشه شامل تمام assetهای برند KidsMeals است که از مستندات رسمی برند استخراج شده‌اند.

## 📁 ساختار

```
public/
├── images/
│   ├── hero/
│   │   ├── hero-bag-and-food.jpg       (کیسه و ظرف غذا)
│   │   ├── hero-boy-eating.jpg         (پسر در حال غذا خوردن)
│   │   └── hero-girl-soup.jpg          (دختر در حال خوردن سوپ)
│   ├── brand/
│   │   ├── logo-color.svg              (لوگوی رنگی)
│   │   ├── logo-white.svg              (لوگوی سفید)
│   │   └── logo-dark.svg               (لوگوی تیره)
│   ├── team/
│   │   └── team-mockup.jpg             (تیم KidsMeals)
│   └── products/
│       └── packaging-mockup.jpg        (بسته‌بندی محصولات)
├── logo.svg                            (لوگوی اصلی)
└── favicon.ico
```

## 🎨 راهنمای استفاده

### لوگو
- **رنگی**: استفاده در header، footer و تمام صفحات
- **سفید**: استفاده روی پس‌زمینه تیره
- **تیره**: استفاده روی پس‌زمینه خیلی روشن

### تصاویر Hero
سه تصویر اصلی برای استفاده در بخش Hero:
1. کیسه و ظرف غذا با tagline "FUELING FUN ADVENTURES!"
2. پسر جوان ایرانی در حال لذت بردن از غذا
3. دختر در حال خوردن سوپ با لبخند

### رنگ‌های برند
تمام رنگ‌ها در `tailwind.config.ts` تعریف شده‌اند.

## ⚠️ نکات مهم

1. **هرگز لوگو را تغییر ندهید** - این asset رسمی برند است
2. **نسبت تصاویر را حفظ کنید** - crop نکنید مگر ضروری باشد
3. **از تصاویر بهینه شده استفاده کنید** - برای وب
4. **Alt text فارسی اضافه کنید** - برای accessibility
